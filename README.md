# Doctocare - Hospital Management System

## Overview

Doctocare is a comprehensive Hospital Management System designed to streamline appointment bookings, patient records, and medical history management.

## College

**Gujarat Technological University (GTU)**

## Developed by

**Yashkumar Pandya**

## Features

- Patient Registration & Login
- Doctor Management
- Appointment Booking System
- Medical History Management
- Admin Dashboard
- Doctor Dashboard
- Patient Dashboard
- Appointment History
- User Authentication & Security
- Profile Management
- Responsive Design

## Project Structure

- `index.php` - Main entry point
- `Doctocare/` - Main application directory
  - `admin/` - Admin panel
  - `doctor/` - Doctor portal
  - `include/` - Shared PHP includes
  - `assets/` - Frontend resources
- `assets/` - Global assets (CSS, JS, images, fonts)
- `SQL File/` - Database schema

## Technology Stack

- **Backend**: PHP
- **Frontend**: HTML5, CSS3, JavaScript
- **Database**: MySQL
- **Framework**: Bootstrap
- **Additional Libraries**: jQuery, Chart.js, DataTables, CKEditor, and more

## Installation

1. Extract the project files to your web root
2. Import the database from `SQL File/hms.sql`
3. Update database credentials in `Doctocare/include/config.php`
4. Access the application through your web browser
